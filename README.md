# 🍴 SmartBite Recipe Finder

SmartBite is a **Flask-based web app** that helps you discover recipes based on ingredients you enter.  
It fetches data from the **Spoonacular API** and also supports a **local fallback JSON** in case the API is slow or unavailable.

---

##  Features
- Search recipes by entering ingredients.
- Displays:
  - Recipe Name
  - Recipe Image
  - Calories, Protein, Carbs, Fat
  - Recipe Link
- Fallback recipes load instantly from `fallback.json` if API fails.
- Simple UI styled with **Bootstrap**.

---

## 🛠️ Tech Stack
- **Backend:** Python, Flask  
- **Frontend:** HTML, CSS, Bootstrap  
- **API:** Spoonacular API  
- **Other:** dotenv for API key management
